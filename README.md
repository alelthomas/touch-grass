# Touch Grass Detector

A fun web app that uses machine learning to detect when you're actually touching grass! Built with Next.js, TensorFlow.js, and MobileNet.

## Features

- Real-time camera access
- ML-powered grass detection
- Mobile-responsive design
- Works on both front and back cameras
- Instant feedback when grass is detected

## Getting Started

1. Clone this repository
2. Install dependencies:

   ```bash
   npm install
   ```

3. Run the development server:

   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser

## How to Use

1. Allow camera access when prompted
2. Point your camera at grass (works best in good lighting)
3. Tap the "Detect Grass" button
4. You'll see a message confirming if grass was detected!

## Technical Details

- Built with Next.js 14
- Uses TensorFlow.js for ML inference
- MobileNet model for image classification
- Tailwind CSS for styling
- TypeScript for type safety

## Requirements

- Modern web browser with camera access
- Node.js 16.17.0 or higher
- NPM 8.15.0 or higher
